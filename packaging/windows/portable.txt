Portable mode

While this file sits next to photocraft.exe, the app keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the Data folder beside it, and writes nothing to
%APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move the app with its settings.

Delete this file to use the normal per-user folders instead (a folder named after the app in
%APPDATA% for settings, and in %LOCALAPPDATA% for crash-recovery autosaves). If Data can't be
written (for example on a read-only drive), the app says so and uses those folders instead.
